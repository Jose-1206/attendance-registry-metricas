# HU-11 — Review attendance for a class session as a teacher

## Story

**As** an authenticated teacher  
**I want** to review attendance records for a class session in one of my courses  
**so that** I can identify which students successfully registered attendance and when they checked in.

## Acceptance criteria

```gherkin
Scenario: Review attendance for my class session
  Given I am authenticated with the TEACHER role
  And an existing class session belongs to one of my courses
  And attendance records exist for that session
  When I request the session's attendance
  Then the system returns only attendance records associated with that session
  And each entry identifies the student and the recorded check-in time
  And the portal displays the attendance list for the selected session

Scenario: Show an empty attendance list
  Given I am authenticated with the TEACHER role
  And an existing class session belongs to one of my courses
  And no attendance records exist for that session
  When I request the session's attendance
  Then the system returns an empty list
  And the portal indicates that no attendance has been recorded for that session

Scenario: Reject access to another teacher's session
  Given I am authenticated with the TEACHER role
  And a class session belongs to another teacher's course
  When I request attendance for that session
  Then the system rejects the operation
  And does not return student attendance information

Scenario: Reject a request for a nonexistent session
  Given I am authenticated with the TEACHER role
  When I request attendance for a session that does not exist
  Then the system rejects the request
  And indicates that the session was not found

Scenario: Display the recorded check-in time under BR-08
  Given I am authenticated with the TEACHER role
  And a student successfully registered attendance for one of my sessions
  When I review that session's attendance
  Then the system returns the check-in time stored when attendance was recorded
  And does not replace it with the time of the review request

Scenario: Reject access by a student
  Given I am authenticated with the STUDENT role
  When I request the teacher session-attendance operation
  Then the system rejects the operation because it requires the TEACHER role
  And does not return the session's attendance list

Scenario: Reject access without a valid JWT
  Given my JWT is missing, invalid, or expired
  When I request attendance for a class session
  Then the system rejects the request as unauthenticated
  And does not return attendance information
```

## Affected module and requirements

| Field | Value |
|---|---|
| Module | `attendance`; see [module boundaries](../../02-domain/module-boundaries.md). |
| Applicable NFR(s) | [NFR-01, NFR-04, NFR-05, NFR-07, NFR-08, NFR-09](../non-functional.md): API performance, JWT validation, role-based authorization, dependency security, coverage on changed backend files, and logging of unhandled backend errors. |
| Business rule(s) touched | **BR-08**: the attendance list displays the check-in time stored when a valid QR scan succeeded. This query does not create or modify attendance records. See [entities and rules](../../02-domain/entities-and-rules.md). |

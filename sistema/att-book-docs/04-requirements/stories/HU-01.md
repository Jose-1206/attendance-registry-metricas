# HU-01 — Register a user account

## Story

**As** a prospective student or teacher  
**I want** to register a user account  
**so that** I can access Attendance Registry with the permissions associated with my role.

## Acceptance criteria

```gherkin
Scenario: Register an account with valid information
  Given no account exists with the submitted email
  When I submit a name, a valid email, a password, and a supported role
  Then the system creates one user account
  And confirms that registration succeeded
  And stores the password as a hash
  And does not expose the password or its hash in the response

Scenario: Reject an email that is already registered
  Given an account already exists with the submitted email
  When I attempt to register another account using that email
  Then the system rejects the registration
  And indicates that the email is already registered
  And does not create another user account

Scenario: Reject an unsupported role
  Given I am completing the registration form
  When I submit a role other than STUDENT or TEACHER
  Then the system rejects the registration
  And indicates that the role is invalid
  And does not create a user account

Scenario: Reject missing required information
  Given I am completing the registration form
  When I submit the form without a name, email, password, or role
  Then the system rejects the registration
  And identifies the missing required information
  And does not create a user account

Scenario: Reject an invalid email format
  Given I am completing the registration form
  When I submit an email with an invalid format
  Then the system rejects the registration
  And indicates that the email format is invalid
  And does not create a user account
```

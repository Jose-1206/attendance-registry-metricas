# HU-02 — Log in to Attendance

## Story

**As** a registered student or teacher\
**I want** to log in using my email and password\
**so that** I can access Attendance Registry features according to my role.

## Acceptance criteria

```gherkin
Scenario: Log in with valid credentials
  Given I have a registered account with the STUDENT or TEACHER role
  When I submit my registered email and correct password
  Then the system authenticates me
  And returns a JWT for accessing protected endpoints
  And the portal displays the authenticated area appropriate to my role
  And the response does not expose my password or password hash

Scenario: Reject an incorrect password
  Given I have a registered account
  When I submit my registered email with an incorrect password
  Then the system rejects the login
  And displays a generic invalid credentials message
  And does not issue a JWT

Scenario: Reject an unregistered email
  Given no account exists with the submitted email
  When I submit that email and a password
  Then the system rejects the login
  And displays the same generic invalid credentials message
  And does not issue a JWT

Scenario: Reject missing credentials
  Given I am on the login page
  When I submit the form without an email or password
  Then the system rejects the submission
  And identifies the missing required information
  And does not issue a JWT

Scenario: Reject access without a valid JWT
  Given I do not have a JWT or my JWT is invalid or expired
  When I request a protected endpoint
  Then the system rejects the request as unauthenticated
  And does not return protected information

Scenario: Reject access to an operation restricted to another role
  Given I am authenticated as a STUDENT
  When I request an operation restricted to the TEACHER role
  Then the system rejects the request as unauthorized for my role
  And does not execute the restricted operation
```

# HU-03 — View my authenticated profile

## Story

**As** an authenticated student or teacher  
**I want** to view my own profile  
**so that** I can confirm the identity and role associated with my current account.

## Acceptance criteria

```gherkin
Scenario: View my own profile
  Given I am authenticated with a valid JWT
  When I request my profile
  Then the system returns my name, email, and role
  And the portal displays my profile information
  And the response does not expose my password or password hash

Scenario: Resolve the profile from the authenticated identity
  Given I am authenticated with a valid JWT
  When I request my profile
  Then the system identifies my account from the authenticated identity
  And returns only the profile associated with that identity

Scenario: Reject a profile request without authentication
  Given I do not provide a JWT
  When I request my profile
  Then the system rejects the request as unauthenticated
  And does not return profile information

Scenario: Reject an invalid or expired JWT
  Given my JWT is invalid or expired
  When I request my profile
  Then the system rejects the request as unauthenticated
  And does not return profile information
  And the portal asks me to log in again
```

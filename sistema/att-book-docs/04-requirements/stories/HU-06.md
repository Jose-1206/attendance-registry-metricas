# HU-06 — Create a class session

## Story

**As** an authenticated teacher  
**I want** to create a class session for one of my courses  
**so that** I can organize attendance for a specific teaching activity.

## Acceptance criteria

```gherkin
Scenario: Create a session for an existing course under BR-04
  Given I am authenticated with the TEACHER role
  And an existing course belongs to my teacher account
  When I submit valid session information for that course
  Then the system creates a class session associated with that course
  And returns the session identifier, course reference, date, start time, and status
  And the portal confirms that the session was created

Scenario: Reject a session for a nonexistent course under BR-04
  Given I am authenticated with the TEACHER role
  When I attempt to create a session for a course that does not exist
  Then the system rejects the request
  And indicates that the course was not found
  And does not create a class session

Scenario: Reject session creation for another teacher's course
  Given I am authenticated with the TEACHER role
  And an existing course belongs to another teacher
  When I attempt to create a session for that course
  Then the system rejects the operation
  And does not create a class session

Scenario: Reject session creation by a student
  Given I am authenticated with the STUDENT role
  When I attempt to create a class session
  Then the system rejects the operation because it requires the TEACHER role
  And does not create a class session

Scenario: Reject missing required session information
  Given I am authenticated with the TEACHER role
  And an existing course belongs to my teacher account
  When I submit session information without a required date or start time
  Then the system rejects the request
  And identifies the missing required information
  And does not create a class session

Scenario: Reject session creation without a valid JWT
  Given my JWT is missing, invalid, or expired
  When I attempt to create a class session
  Then the system rejects the request as unauthenticated
  And does not create a class session
```

## Affected module and requirements

| Field | Value |
|---|---|
| Module | `class-sessions`; see [module boundaries](../../02-domain/module-boundaries.md). |

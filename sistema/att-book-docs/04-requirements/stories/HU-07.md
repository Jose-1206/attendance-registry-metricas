# HU-07 — View class sessions for a course

## Story

**As** an authenticated teacher  
**I want** to view the class sessions for one of my courses  
**so that** I can select a session and continue its QR and attendance activities.

## Acceptance criteria

```gherkin
Scenario: View sessions for my course
  Given I am authenticated with the TEACHER role
  And an existing course belongs to my teacher account
  And class sessions exist for that course
  When I request the course's class sessions
  Then the system returns only the sessions associated with that course
  And each session includes its identifier, course reference, date, start time, and status
  And the portal displays the returned sessions

Scenario: Show an empty session list
  Given I am authenticated with the TEACHER role
  And an existing course belongs to my teacher account
  And no class sessions exist for that course
  When I request the course's class sessions
  Then the system returns an empty list
  And the portal indicates that the course has no class sessions yet

Scenario: Reject a request for a nonexistent course
  Given I am authenticated with the TEACHER role
  When I request sessions for a course that does not exist
  Then the system rejects the request
  And indicates that the course was not found

Scenario: Reject access to another teacher's course sessions
  Given I am authenticated with the TEACHER role
  And an existing course belongs to another teacher
  When I request that course's class sessions
  Then the system rejects the operation
  And does not return the course's session information

Scenario: Reject access without a valid JWT
  Given my JWT is missing, invalid, or expired
  When I request a course's class sessions
  Then the system rejects the request as unauthenticated
  And does not return session information
```

# HU-04 — Create a course

## Story

**As** an authenticated teacher  
**I want** to create a course  
**so that** I can organize the class sessions and attendance associated with my teaching activities.

## Acceptance criteria

```gherkin
Scenario: Create a course as a teacher
  Given I am authenticated with the TEACHER role
  When I submit a course name and code that satisfy the agreed validation rules
  Then the system creates the course
  And associates it with my authenticated teacher account
  And returns the created course information
  And the portal confirms that the course was created

Scenario: Reject course creation by a student under BR-01
  Given I am authenticated with the STUDENT role
  When I attempt to create a course
  Then the system rejects the operation because it requires the TEACHER role
  And does not create a course

Scenario: Reject course creation without authentication
  Given I do not provide a JWT
  When I attempt to create a course
  Then the system rejects the request as unauthenticated
  And does not create a course

Scenario: Reject course creation with an invalid or expired JWT
  Given my JWT is invalid or expired
  When I attempt to create a course
  Then the system rejects the request as unauthenticated
  And does not create a course

Scenario: Reject missing course information
  Given I am authenticated with the TEACHER role
  When I submit a course without a required name or code
  Then the system rejects the request
  And identifies the missing required information
  And does not create a course
```

## Affected module and requirements

| Field | Value |
|---|---|
| Module | `academic`; see [module boundaries](../../02-domain/module-boundaries.md). |
| Applicable NFR(s) | [NFR-01, NFR-04, NFR-05, NFR-07, NFR-08, NFR-09](../non-functional.md): API performance, JWT validation, role-based authorization, dependency security, coverage on changed backend files, and logging of unhandled backend errors. |
| Business rule(s) touched | **BR-01**: only users with the `TEACHER` role can create and manage courses. The `Course` entity must reference a registered teacher. See [entities and rules](../../02-domain/entities-and-rules.md). |

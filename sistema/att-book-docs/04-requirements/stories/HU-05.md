# HU-05 — View my courses as a teacher

## Story

**As** an authenticated teacher  
**I want** to view the courses associated with my account  
**so that** I can select a course and access its class sessions and attendance activities.

## Acceptance criteria

```gherkin
Scenario: View my courses
  Given I am authenticated with the TEACHER role
  And courses are associated with my teacher account
  When I request my courses
  Then the system returns the courses associated with my authenticated account
  And each course includes its identifier, name, and code
  And the portal displays the returned courses

Scenario: Show an empty course list
  Given I am authenticated with the TEACHER role
  And no courses are associated with my account
  When I request my courses
  Then the system returns an empty list
  And the portal indicates that I have no courses yet

Scenario: Exclude another teacher's courses
  Given I am authenticated with the TEACHER role
  And a course belongs to another teacher
  When I request my courses
  Then that course is not included in my course list

Scenario: Reject access by a student
  Given I am authenticated with the STUDENT role
  When I request the teacher course list
  Then the system rejects the operation because it requires the TEACHER role
  And does not return the teacher course list

Scenario: Reject access without a valid JWT
  Given my JWT is missing, invalid, or expired
  When I request my courses
  Then the system rejects the request as unauthenticated
  And does not return course information
```

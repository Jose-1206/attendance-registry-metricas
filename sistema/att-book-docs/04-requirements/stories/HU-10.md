# HU-10 — View my attendance history as a student

## Story

**As** an authenticated student  
**I want** to view my attendance history  
**so that** I can review the class sessions for which my attendance was successfully recorded.

## Acceptance criteria

```gherkin
Scenario: View my attendance history
  Given I am authenticated with the STUDENT role
  And attendance records exist for my account
  When I request my attendance history
  Then the system returns only attendance records associated with my authenticated account
  And each entry identifies the course, class session, and recorded check-in time
  And the portal displays the returned attendance history

Scenario: Show an empty attendance history
  Given I am authenticated with the STUDENT role
  And no attendance records exist for my account
  When I request my attendance history
  Then the system returns an empty list
  And the portal indicates that I have no attendance records yet

Scenario: Exclude another student's attendance
  Given I am authenticated with the STUDENT role
  And attendance records exist for another student
  When I request my attendance history
  Then the system does not include the other student's attendance records

Scenario: Display the original check-in time under BR-08
  Given I am authenticated with the STUDENT role
  And an attendance record exists for a successful QR check-in
  When I view that record in my attendance history
  Then the system displays the check-in time stored when attendance was recorded
  And does not replace it with the time of the history request

Scenario: Reject access by a teacher
  Given I am authenticated with the TEACHER role
  When I request the student attendance-history operation
  Then the system rejects the operation because it requires the STUDENT role
  And does not return student attendance history

Scenario: Reject access without a valid JWT
  Given my JWT is missing, invalid, or expired
  When I request my attendance history
  Then the system rejects the request as unauthenticated
  And does not return attendance information
```

## Affected module and requirements

| Field | Value |
|---|---|
| Module | `attendance`; see [module boundaries](../../02-domain/module-boundaries.md). |
| Applicable NFR(s) | [NFR-01, NFR-04, NFR-05, NFR-07, NFR-08, NFR-09](../non-functional.md): API performance, JWT validation, role-based authorization, dependency security, coverage on changed backend files, and logging of unhandled backend errors. |
| Business rule(s) touched | **BR-08**: the history displays the check-in time stored when a valid QR scan succeeded. This query does not create or modify attendance records. See [entities and rules](../../02-domain/entities-and-rules.md). |
